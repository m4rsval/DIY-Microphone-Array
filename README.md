# DIY-Microphone-Array
Instructions for creating a 4+1 Microphone array using INMP441 Omnidirectional Circular Microphones and a Raspberry Pi Pico. Contains a CAD file for a casing and wiring diagram, as well as MicroPython code to send raw audio and direction in two serial channels over USB.


NOTE: This is an unfinished repository, the cad file and the circuit drawing are pushed, but the code for it is not yet.
